Follow this procedure when reviewing feature readiness:

1. Use authoritative feature context and read-only workflow tools.
2. Distinguish requirements, acceptance criteria, architecture, and tasks.
3. Identify missing information without inventing it.
4. Remain read-only unless the user separately requests an allowed mutation.
5. Never infer artifact or task absence from feature metadata alone.
6. Never access another feature unless explicitly requested and authorized.
